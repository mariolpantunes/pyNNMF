 40    """
 41    Robust Weighted Non-negative Matrix Factorization (RWNMF) with L2 regularization.
 42
 43    Optimizes the Frobenius norm objective function with missing values and L2 regularization:
 44
 45    $$D_{\\text{Fro}}(X \\parallel U V^T) = \\frac{1}{2} \\| M \\odot (X - U V^T) \\|_F^2 + \\frac{\\alpha}{2} (\\|U\\|_F^2 + \\|V\\|_F^2)$$
 46
 47    where $M$ is a binary mask representing observed values (1 if observed, 0 if NaN).
 48
 49    Optimization method: Multiplicative Update (MU) rules.
 50
 51    $$U \\leftarrow U \\odot \\frac{(M \\odot X) V}{(M \\odot (U V^T)) V + \\alpha U}$$
 52
 53    $$V \\leftarrow V \\odot \\frac{(M \\odot X)^T U}{(M \\odot (U V^T))^T U + \\alpha V}$$
 54
 55    Args:
 56        x (np.ndarray): Target matrix of shape (m, n) with potential NaN values.
 57        k (int): Number of latent components.
 58        alpha (float): L2 regularization parameter. Defaults to 0.1.
 59        tol_fit_improvement (float): Early stopping tolerance for reconstruction improvement. Defaults to 1e-4.
 60        tol_fit_error (float): Early stopping tolerance for reconstruction error. Defaults to 1e-4.
 61        num_iter (int): Maximum number of iterations. Defaults to 1000.
 62        seed (int, optional): Random seed for reproducibility. Defaults to None.
 63        eval_every (int): Frequency of checking early-stopping criteria. Defaults to 10.
 64        init (str or callable): Initialization method ('random', 'nndsvd', 'svd_impute')
 65                                or a custom callable. Defaults to 'random'.
 66
 67    Returns:
 68        tuple: (xr, u, v, error)
 69            - xr (np.ndarray): Reconstructed matrix of shape (m, n).
 70            - u (np.ndarray): Left factor matrix of shape (m, k).
 71            - v (np.ndarray): Right factor matrix of shape (n, k).
 72            - error (float): Final Frobenius reconstruction error.
 73    """
 74    eps = np.finfo(float).eps
 75    early_stop = False
 76
 77    m_mask = np.isnan(x)
 78    x_copy = x.copy()
 79    x_copy[m_mask] = 0
 80    m_not = ~m_mask
 81
 82    u, v = initialize_nmf(x, k, method=init, seed=seed)
 83    v: np_typing.NDArray[np.floating] = v.T
 84
 85    xr: np_typing.NDArray[np.floating] = np.inf * np.ones(x.shape)
 86
 87    m_float = m_not.astype(float)
 88    m_x = m_float * x_copy
 89    m_x_t = m_x.T
 90
 91    # Initial rec
 92    rec: np_typing.NDArray[np.floating] = u @ v.T
 93
 94    for i in range(num_iter):
 95        # 1. Update u
 96        rec = rec * m_float
 97        u: np_typing.NDArray[np.floating] = u * ((m_x @ v) / (rec @ v + alpha * u))
 98        u = np.maximum(u, eps)
 99
100        # 2. Update v
101        rec = u @ v.T
102        rec = rec * m_float
103        v: np_typing.NDArray[np.floating] = v * ((m_x_t @ u) / (rec.T @ u + alpha * v))
104        v = np.maximum(v, eps)
105
106        # residuals evaluation
107        rec = u @ v.T
108        if i % eval_every == 0:
109            fit_error: float = float(np.linalg.norm(x_copy - rec, "fro"))
110            fit_improvement: float = float(np.linalg.norm(rec - xr, "fro"))
111            xr = np.copy(rec)
112
113            if fit_error < tol_fit_error or fit_improvement < tol_fit_improvement:
114                early_stop = True
115                break
116
117    if early_stop:
118        xr = rec
119    else:
120        xr = u @ v.T
121
122    error = np.linalg.norm(x_copy - xr, ord="fro")
123    return xr, u, v, float(error)

Robust Weighted Non-negative Matrix Factorization (RWNMF) with L2 regularization.

Optimizes the Frobenius norm objective function with missing values and L2 regularization:

$$D_{\text{Fro}}(X \parallel U V^T) = \frac{1}{2} \| M \odot (X - U V^T) \|_F^2 + \frac{\alpha}{2} (\|U\|_F^2 + \|V\|_F^2)$$

where $M$ is a binary mask representing observed values (1 if observed, 0 if NaN).

Optimization method: Multiplicative Update (MU) rules.

$$U \leftarrow U \odot \frac{(M \odot X) V}{(M \odot (U V^T)) V + \alpha U}$$

$$V \leftarrow V \odot \frac{(M \odot X)^T U}{(M \odot (U V^T))^T U + \alpha V}$$

Arguments:
  • x (np.ndarray): Target matrix of shape (m, n) with potential NaN values.
  • k (int): Number of latent components.
  • alpha (float): L2 regularization parameter. Defaults to 0.1.
  • tol_fit_improvement (float): Early stopping tolerance for reconstruction improvement. Defaults to 1e-4.
  • tol_fit_error (float): Early stopping tolerance for reconstruction error. Defaults to 1e-4.
  • num_iter (int): Maximum number of iterations. Defaults to 1000.
  • seed (int, optional): Random seed for reproducibility. Defaults to None.
  • eval_every (int): Frequency of checking early-stopping criteria. Defaults to 10.
  • init (str or callable): Initialization method ('random', 'nndsvd', 'svd_impute') or a custom callable. Defaults to 'random'.

158    """
159    Compute the Kullback-Leibler (KL) divergence cost between two matrices.
160
161    $$D_{\\text{KL}}(A \\parallel B) = \\sum_{i,j} M_{ij} \\left( A_{ij} \\log \\frac{A_{ij}}{B_{ij}} - A_{ij} + B_{ij} \\right)$$
162
163    Args:
164        a (np.ndarray): Target matrix.
165        b (np.ndarray): Reconstructed matrix.
166        m (np.ndarray, optional): Binary mask of observed elements. Defaults to None.
167
168    Returns:
169        float: KL divergence cost.
170    """
171    if m is None:
172        m = ~np.isnan(a)
173    mask = m & (a > 0.0)
174    a_vals = a[mask]
175    b_vals = b[mask]
176    term_pos = a_vals * np.log(a_vals / b_vals) - a_vals
177    term_b = b[m]
178    return float(np.sum(term_pos) + np.sum(term_b))

489def nmf_als(
490    x: np_typing.NDArray[np.floating],
491    k: int,
492    n: int = 1000,
493    tol: float = 1e-3,
494    seed: int | None = None,
495    eval_every: int = 10,
496    init: Literal["random", "nndsvd", "svd_impute"]
497    | Callable[
498        [np_typing.NDArray[np.floating], int], tuple[np_typing.NDArray[np.floating], np_typing.NDArray[np.floating]]
499    ] = "random",
500    callback: Callable[[int, float], None] | None = None,
501) -> tuple[np_typing.NDArray[np.floating], np_typing.NDArray[np.floating], np_typing.NDArray[np.floating], float]:
502    """
503    Alternating Least Squares (ALS) NMF with missing values imputation.
504
505    Minimizes the Frobenius norm. During each iteration, missing entries (NaNs)
506    are imputed dynamically from the current reconstruction:
507
508    $$X_{\\text{imp}} = M \\odot X + (1 - M) \\odot (W H)$$
509
510    Then, least squares solutions are computed alternately:
511
512    $$W \\leftarrow \\max\\left(\\epsilon, X_{\\text{imp}} H^T (H H^T + 10^{-9} I_k)^{-1}\\right)$$
513
514    $$H \\leftarrow \\max\\left(\\epsilon, (W^T W + 10^{-9} I_k)^{-1} W^T X_{\\text{imp}}\\right)$$
515
516    Args:
517        x (np.ndarray): Target matrix of shape (m, n).
518        k (int): Number of latent components.
519        n (int): Maximum number of iterations. Defaults to 1000.
520        tol (float): Convergence tolerance. Defaults to 1e-3.
521        seed (int, optional): Random seed. Defaults to None.
522        eval_every (int): Frequency of checking early-stopping criteria. Defaults to 10.
523        init (str or callable): Initialization method ('random', 'nndsvd', 'svd_impute')
524                                or a custom callable. Defaults to 'random'.
525        callback (callable, optional): Function called at each iteration with (iteration, cost). Defaults to None.
526
527    Returns:
528        tuple: (rec, w, h, cost)
529            - rec (np.ndarray): Reconstructed matrix.
530            - w (np.ndarray): Left factor matrix.
531            - h (np.ndarray): Right factor matrix.
532            - cost (float): Final Frobenius cost.
533    """
534    eps = 1e-9
535    w, h = initialize_nmf(x, k, method=init, seed=seed)
536
537    m_mask = np.isnan(x)
538    x_copy = x.copy()
539    x_copy[m_mask] = 0
540    m_not = ~m_mask
541    m_float = m_not.astype(float)
542    x_zero = m_mask
543
544    rec: np_typing.NDArray[np.floating] = w @ h
545    cost = cost_fb(x_copy, rec, m_float)
546
547    for idx in range(n):
548        # Imputation
549        rec = w @ h
550        x_imp: np_typing.NDArray[np.floating] = np.where(x_zero, rec, x_copy)
551
552        # Update w

Alternating Least Squares (ALS) NMF with missing values imputation.

Minimizes the Frobenius norm. During each iteration, missing entries (NaNs) are imputed dynamically from the current reconstruction:

$$X_{\text{imp}} = M \odot X + (1 - M) \odot (W H)$$

Then, least squares solutions are computed alternately:

$$W \leftarrow \max\left(\epsilon, X_{\text{imp}} H^T (H H^T + 10^{-9} I_k)^{-1}\right)$$

$$H \leftarrow \max\left(\epsilon, (W^T W + 10^{-9} I_k)^{-1} W^T X_{\text{imp}}\right)$$

  • x (np.ndarray): Target matrix of shape (m, n).
  • k (int): Number of latent components.
  • n (int): Maximum number of iterations. Defaults to 1000.
  • tol (float): Convergence tolerance. Defaults to 1e-3.
  • seed (int, optional): Random seed. Defaults to None.
  • eval_every (int): Frequency of checking early-stopping criteria. Defaults to 10.
  • init (str or callable): Initialization method ('random', 'nndsvd', 'svd_impute') or a custom callable. Defaults to 'random'.
  • callback (callable, optional): Function called at each iteration with (iteration, cost). Defaults to None.
Returns:
